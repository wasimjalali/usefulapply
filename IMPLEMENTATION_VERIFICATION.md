## 5. Anti-Invention Rules

**File:** `src/lib/agents/writer-agent.ts` (lines 375-416)

### System Prompt Contains:

```
ABSOLUTE PROHIBITIONS - NEVER USE THESE:
- "I am writing to apply for..." or "I am excited to apply for..."
- "I believe I would be a great fit..."
- "Thank you for considering my application..."
- "To Whom It May Concern"
- "I am confident that..."
- "I would be a valuable asset..."
- "I am a [adjective] professional..."
- "References available upon request"
- "Please find attached..."
- "I look forward to hearing from you"
- Any phrase containing "passionate" without specific evidence
```

### User Prompt Contains (line 371):

```
6. Verify every claim exists in the CV - never invent achievements
```

### ⚠️ MISSING: Explicit "NEVER INVENT" in System Prompt

The system prompt focuses on cliché prohibitions but does NOT explicitly state:
- "NEVER invent skills, experiences, or achievements"
- "Only use information from the provided CV"

**Recommendation:** Add to system prompt:
```
CRITICAL ANTI-HALLUCINATION RULE:
- NEVER invent skills, experiences, achievements, or metrics
- ONLY reference information explicitly stated in the CANDIDATE BACKGROUND section
- If the CV lacks specific metrics, use qualitative descriptions instead of making up numbers
```

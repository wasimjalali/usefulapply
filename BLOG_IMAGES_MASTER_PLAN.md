## 📚 Imagen 3 Best Practices (Google's Latest Image Generation Model)

### Quality Settings
- **Model:** Imagen 3 (accessed via Gemini interface - most advanced, photorealistic quality)
- **Aspect Ratio:** Wide (16:9) for in-post images, Square for cover images
- **Style Options:** Choose from Gemini style presets or specify in prompt
- **Output:** High-resolution, professional quality

### Imagen 3 Prompt Optimization
1. **Be Extremely Specific:** Imagen 3 excels with detailed descriptions
2. **Natural Language:** Write like you're describing to a human, not code
3. **Visual Hierarchy:** Describe foreground, midground, background
4. **Lighting & Mood:** Always specify (e.g., "soft natural lighting", "professional studio lighting")
5. **Composition:** Mention layout explicitly (centered, split-screen, balanced, etc.)
6. **Colors First:** Start with color palette to ensure brand consistency
7. **Style Clarity:** Be explicit: "flat design illustration", "photorealistic", "3D render", "infographic style"
8. **Avoid Negatives:** Say what you WANT, not what you don't want
9. **Single Focus:** One clear subject per image works best
10. **Professional Context:** Add "professional business context" for corporate aesthetics

### Imagen 3 Strengths
- **Photorealism:** Best-in-class for realistic images
- **Text Rendering:** Can include text in images (useful for charts/labels)
- **Brand Consistency:** Maintains colors and style well across batch
- **Complex Compositions:** Handles split-screens and diagrams better than competitors
- **Fine Details:** Excellent at small UI elements, icons, charts

### Prompt Formula for Business Graphics
```
[COMPOSITION TYPE] showing [MAIN SUBJECT] with [KEY ELEMENTS]. [STYLE] with [COLOR SCHEME]. [LIGHTING]. Professional, clean, high-quality. [SPECIFIC DETAILS].
```

**Example:**
"Professional bar chart showing follow-up email response rates. Two vertical bars: left bar 25% in gray labeled 'No Follow-Up', right bar 40% in gold (#FFD700) labeled 'With Follow-Up'. Navy blue (#0F3057) gradient background, soft lighting. Clean modern infographic style with clear percentage labels above bars. Minimal grid lines, business professional aesthetic."

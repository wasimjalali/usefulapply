## Missing from the plan

- Free draft creation, direct CV/letter/email edits, primary/master CV deletion and photo upload/removal. Humans already have these through `src/db/actions.ts:139`, `CVPanel.tsx:484`, `CoverLetterPanel.tsx:477` and `EmailPanel.tsx:274`.
- Career-profile/search-strategy operations, feed consent withdrawal and complete feed settings, including automation and timezone. Relevant routes exist under `src/app/api/job-feed/`.
- `get_cv_outline`, required by the proposed reused editing tools; language override; `.txt`, `.md` and `.tex` upload parity. Add `cv_docx` to §4a's export enum.
- Queue consumer wiring through OpenNext request context (`src/worker.ts:41`, `src/db/client.ts:29`). Specify ID-only messages, batching, concurrency and deadlines against the [128 KB message, 15-minute wall-time and default 30-second CPU limits](https://developers.cloudflare.com/queues/platform/limits/).
- Negative E2E coverage: cross-user IDs, expired/replayed render grants, refresh/revocation, duplicate requests, Queue crashes, partial refunds and stale-tab writes. Use Playwright Test with trace/video.
- Retention/deletion rules and disclosures covering R2 exports, Browser Run and analytics; renewable reviewer credits and seeded fixtures. Anthropic requires testing every tool in Claude, not just one workflow ([submission checklist](https://claude.com/docs/connectors/building/submission)).

## DISMISSED

- One server for multiple clients: sound; packaging can remain client-specific.
- Stateless MCP and deprecated McpAgent: supported by [Cloudflare's current SDK documentation](https://developers.cloudflare.com/changelog/post/2026-07-27-agents-sdk-v0.20.0-mcp-sdk-v2/).
- Better Auth MCP/CIMD direction: current and appropriate; durable OAuth records remain necessary.
- The 1.5-credit continuation price: correct in `src/lib/credit-costs.ts:3`; AGENTS.md's summary is stale.
- Existing paid-account access: allowed; excluding checkout tools is appropriate.
- Client components: `'use client'` alone doesn't prevent server prerendering, though GermanClassic currently imports settings behavior.
- html2canvas replacement: justified; today's CV export is rasterized.
- oklch: no demonstrated Chromium blocker; the existing workaround targets html2canvas.
- Queue generation: justified for disconnect survival; return an operation immediately by default instead of making every client wait 45 seconds.

## Verdict

Revise before implementation. One MCP server and shared services are sound choices, but the plan doesn’t yet guarantee durable generation, safe concurrent editing, export fidelity or directory acceptance. The largest risks are treating credit reservations as complete idempotency and treating browser-dependent chat tools as reusable server capabilities.

## Missing from the plan

- **Direct editing parity:** humans can edit CV fields, cover letters and email subjects/bodies without paid regeneration. Add revision-checked editing operations. Evidence: `CVPanel.tsx:484`, `CoverLetterPanel.tsx:310`, `EmailPanel.tsx:77`.
- **Document lifecycle:** primary/master deletion and structured corrections, plus photo upload/removal. Evidence: `src/db/actions.ts:134,139`, `GeneralPane.tsx:141`.
- **Feed onboarding:** a new account cannot satisfy “consent required” through the listed tools. Specify consent, enable/disable and all editable preferences. Existing chat explicitly redirects unconfigured users to the website (`feed-tools.ts:537`).
- **Notification preferences:** tracker dates don't independently authorize reminder emails. Expose existing notification controls (`NotificationsPane.tsx:13`).
- **Async result contract:** return operation ID, pending versus actual credits, partial-document errors and polling guidance immediately. The 45-second wait should be optional, not the correctness mechanism.
- **Simplification:** extract existing repo-backed services incrementally. Prefer self-contained print HTML with embedded authorized assets if it removes print-token routes without sacrificing renderer parity.

## DISMISSED

- **One server for all clients:** appropriate; separate servers would duplicate authorization and business rules.
- **Stateless MCP and McpAgent deprecation:** confirmed by [Cloudflare's current handler documentation](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/).
- **1.5 credits after fit:** correct in `src/lib/credit-costs.ts:3`; AGENTS.md's price table is stale.
- **Arial/Georgia availability:** both are documented [Browser Run fonts](https://developers.cloudflare.com/browser-run/reference/supported-fonts/).
- **Client components preventing SSR:** `'use client'` alone doesn't prevent initial server rendering.
- **oklch requiring raster export:** Chromium rendering avoids html2canvas's parser limitation.
- **Existing paid accounts:** OpenAI permits access to already-purchased entitlements; checkout and upsells remain excluded.
- **Interview-prep omission:** it isn't implemented yet (`src/db/schema.ts:389`).
- **Existing repository IDOR:** sampled session/file paths check ownership; new capability URLs still require their own controls.

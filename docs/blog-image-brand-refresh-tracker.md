# Blog Image Brand Refresh Tracker

Goal: replace legacy blog imagery with GPT Image-2 generated brand illustrations in the shared Karko style.

Shared style for replacement images:
- Flat editorial illustration, vector-style
- Warm cream background `#FAF7F2`
- Navy `#1E3A5F` and gold `#D4A853` as the only accent colors
- No text inside images
- No photographs, screenshots, external logos, or realistic rendering
- Solid fills only, clean minimal composition
- 16:9, `1600 x 900`, JPG, optimized under 250KB

## Per-Post Checklist

- Read the blog content and current image placements.
- Decide the smallest useful image set, including the cover.
- Generate GPT Image-2 replacements in shared brand style.
- Convert to optimized JPG under 250KB.
- Replace legacy files or update markdown references where reducing image count improves the post.
- Confirm dimensions, file sizes, and no accidental blog content drift.
- Commit and push the completed post batch.
